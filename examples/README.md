# Examples

Sanitized before/after examples showing what Job Hunter output looks like.

These three are seed examples from the original job search that inspired this project.
They cover the most common tools — LinkedIn audit, resume tailoring, and cover letter.

**The best examples come from real job searches.**
If you've used Job Hunter and want to contribute a sanitized example:
- Remove all real names, companies, titles, locations, and contact info
- Replace with generic placeholders: `[Company A]`, `[Role Title]`, `[Your Name]`
- Keep the structure and quality signal intact — that's what makes them useful
- Submit via pull request or open an issue

See [docs/CONTRIBUTING.md](../docs/CONTRIBUTING.md) for guidelines.

## Current examples

| File | Tool | What it shows |
|---|---|---|
| `linkedin-audit-example.md` | `npm run linkedin` | Before/after headline, about section, experience bullets, keyword gaps |
| `resume-tailored-example.md` | `npm run resume` | Before/after summary and bullets, gaps section |
| `cover-letter-example.md` | `npm run cover-letter` | Full cover letter output with annotations |
