JobHunter
Free & open source — let's get you set up in 2 minutes
1
Create a free Anthropic account
Go to console.anthropic.com and sign up — it's free. This is separate from Claude.ai but uses the same email.
2
Add a small credit balance
Once logged in, go to Billing and add $5. Each job application costs about 2–5 cents, so $5 covers roughly 100–200 uses.
3
Get your API key and paste it here
Go to API Keys, click Create Key, copy it, and paste it below. It starts with sk-ant-
🔒 Your API key is saved only in your browser. It never touches our servers — requests go directly from your browser to Anthropic.
