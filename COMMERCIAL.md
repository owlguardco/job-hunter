# Commercial Use

Job Hunter is MIT licensed. You can use it, fork it, and build on it — including commercially.

## The official hosted version

The maintainer (owlguardco) runs a hosted pay-per-use version of this tool at:

**https://jobhunter.ai** *(coming soon)*

- No setup required — sign up and go
- $0.25 per run, or monthly unlimited
- Same agents and rules engine as the open source version
- Your API key isn't needed — we handle infrastructure

## Self-hosting (free)

Clone the repo, add your own Anthropic API key, and run it locally.
This will always be free. See [README.md](README.md) for setup.

## Building a commercial product on this codebase

You're welcome to fork and build a commercial product. MIT license permits it.

If you do:
- You cannot use the "Job Hunter" name or logo for a competing hosted service
- Attribution appreciated but not required
- If you build something useful on top of this, consider contributing improvements back

## For contributors

Contributing to this repo means your contributions may be used in the hosted
commercial version. That's the standard open core model — your work improves
both the free and paid versions.

There's no contributor license agreement required. MIT covers it.
